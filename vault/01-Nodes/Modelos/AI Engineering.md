# AI Engineering
## Definição 

> [!NOTE]
> Prática de construir aplicações e sistemas de IA utilizando foundation models previamente treinados como componentes fundamentais. 

--- 
## Intuição 

O modelo fornece capacidade.

A engenharia transforma essa capacidade em um sistema utilizável. 
```text 
Foundation Model 
↓ 
Engenharia 
↓ 
Aplicação 
↓ 
Produto 

```


## Por que existe?

Foundation models conseguem executar muitas tarefas, mas possuem limitações  
que precisam ser tratadas quando são utilizados em aplicações reais.

Entre elas:

- respostas inconsistentes;
- alucinações;
- conhecimento incompleto;
- custo;
- latência;
- segurança;
- dificuldade de avaliação.

---

## Modelo não é aplicação

```
LLM ≠ Aplicação
```

O modelo é apenas um componente:

```
LLM ∈ Aplicação
```
