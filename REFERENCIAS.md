# Referências

## Natureza deste repositório

Este repositório é **independente e autoral**.

Todo o material publicado aqui — aulas, notas conceituais, diagramas,
laboratórios, código e experimentos — é produzido de forma original pelos
autores do projeto.

Obras externas são utilizadas **exclusivamente como referência de estudo**.
Este repositório:

- **não** distribui livros, PDFs ou capítulos;
- **não** reproduz textos extensos de obras protegidas;
- **não** reproduz figuras, tabelas ou diagramas de obras protegidas;
- **não** substitui a leitura das fontes originais.

Exemplos e implementações são desenvolvidos de forma independente, salvo
quando explicitamente indicado no próprio arquivo e permitido pela licença
da fonte. Nesses casos, a fonte e a licença são citadas junto ao trecho.

Quando um conceito é aprendido a partir de uma fonte específica, a fonte é
citada — mas a explicação é reescrita com palavras próprias.

# Como citar uma fonte neste repositório

Ao adicionar conteúdo derivado de uma fonte externa, registre no rodapé da
nota ou do laboratório:

```markdown
## Referências

- SOBRENOME, Nome. *Título da obra*. Editora, ano. Capítulo/seção consultada.
- Título do artigo — URL (acesso em AAAA-MM-DD)
```

Regras:

1. Cite sempre a fonte de onde o conceito veio.
2. Reescreva a explicação com suas próprias palavras.
3. Nunca cole trechos longos de material protegido.
4. Nunca inclua arquivos de obras protegidas no repositório.
